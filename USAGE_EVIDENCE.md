# Usage Evidence

This ledger records public-safe evidence from voluntary first uses of the
starter. It is not a customer list, analytics store, or claim of representative
adoption, and there is no participation target. Each report should use
generalized or synthetic details only.

| Starter version | Work type | Outcome | First friction | Trust signal | Smallest supported correction | Public report |
| --- | --- | --- | --- | --- | --- | --- |

## Evidence Rules

- Add a row only from a public first-use report whose author chose to share it.
- Record the outcome honestly: used, edited, rejected, or could not complete.
- Do not import private source material, raw logs, identifying details, or
  unpublished work.
- Use reports only to support the smallest correction they directly justify;
  they cannot establish broad effectiveness.
- Tie each starter change to the report that supports it, or label the change
  as maintainer judgement rather than user evidence.
