# Contributing

Tried the starter? A short report about where you got stuck or what you
changed can help improve it. Sharing feedback is optional.

Use the structured first-use report and remove private messages, credentials,
personal records, customer data, internal links, connector exports, raw model
logs, and unpublished material before submitting anything.

For code or documentation changes:

1. Keep the starter small and dependency-free.
2. Use synthetic examples only.
3. Explain what made first use difficult and how the change helps.
4. Run `python3 -B check_starter.py`.
5. State what the check confirms and what a person still needs to decide.
