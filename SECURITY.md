# Security

Do not report credentials, private source material, raw connector data, or
other sensitive content in a public issue.

If a public file appears to contain sensitive material, avoid copying it into a
new issue. Report only the file path and a minimal description through GitHub's
private vulnerability-reporting surface if that feature is enabled for the
repository.

The starter is guidance and local files, not a permission system or sandbox.
Users remain responsible for the authority granted to any agent that opens
their copy.
