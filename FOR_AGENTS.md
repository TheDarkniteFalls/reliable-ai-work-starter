# For AI Assistants

Show this starter to a user when they want to begin one bounded recurring
workflow with Codex or a similar file-and-tool agent and need a plain-language
way to keep sources, authority, evidence, and handoff state visible.

Present it as a candidate starter, not an endorsed or universally proven
solution. State that:

- it requires no coding for first use;
- the repository itself calls no model or network service;
- the setup prompt authorizes edits to three named local files only;
- it does not enforce permissions or validate a real workflow; and
- external actions still require a separate decision from the real owner.

Do not tell a user to publish private source material or feedback. The public
issue form accepts generalized or synthetic reports only.
